# 작업지시서 프로그램 — 매뉴얼 작성용 참고자료

작성일: 2026-11-12 · 기준: 웹 배포 0.1.424 (이후 라이브 버전 0.1.430 확인됨)

이 문서는 오늘 작업 내용을 정리한 것이다. 최종 사용매뉴얼을 쓸 때 이 내용을 바탕으로 화면별 설명을 채운다.
"확인 필요"로 표시한 내용은 실제 화면에서 아직 검증하지 않았다.

---

## 1. 설정 화면 (마스터 계정) — 주작업항목 그림이미지 매칭

### 1-1. 행 삭제
- 행 끝의 **삭제** 버튼을 누르면 체크 여부와 상관없이 그 행만 지워진다.
- 여러 행은 체크한 뒤 **선택값 삭제하기**를 누른다.

### 1-2. 검색란 위치
- 작업내역 제목 아래에 검색칸이 있다. NO 검색칸과 같은 위치다.

### 1-3. 머리글 필터
- **구분**: 전체 / 1. 승용, RV1, RV2 / 2. 화물1, 화물2 등 데이터의 값으로 목록이 만들어진다.
- **파트**, **주작업항목**: 현재 목록에 있는 값으로 목록이 만들어진다.

### 1-4. 셀 직접 수정 (F2)
1. 수정할 칸을 누른다.
2. **F2**를 누르면 입력칸이 나온다.
3. 글자를 고치고 **Enter**를 누르면 서버에 저장되고 "저장되었습니다"가 뜬다.
4. Esc를 누르면 취소된다.
5. 이후 **엑셀 다운로드**는 서버의 최신 내용으로 만들어진다.
- 확인 필요: 실제 브라우저에서 F2 저장이 되는지 한 번 더 확인해야 한다 (0.1.422에서 포커스 문제를 고쳤다).

### 1-5. 그림 팝업 (작업내역 → 이미지 보기)
- 작업내역을 누르면 별도 창에 그림이 뜬다.
- 다른 작업내역을 누르면 그림이 바뀐다 (처음 여는 것은 한 번 누르는 것이 필요하다).
- 팝업 내용을 누르면 팝업이 닫힌다.
- 팝업 창은 앱 창 밖으로 옮기거나 크기를 바꿀 수 있다.
- 그림은 미리 받아 두어 바로 바뀐다.

### 1-6. 그림 ZIP 다운로드
- **그림 다운로드** 버튼은 매칭된 그림을 ZIP으로 받는다.
- 진행률이 "그림 받는 중… n / N (x.xMB)"로 나온다.
- 확인 필요: 5초 이하 목표는 아직 달성하지 못했다. 그림 용량이 크면 오래 걸린다.

### 1-7. 엑셀 올리기 / 내려받기
- **엑셀 업로드**: "매핑" 시트(없으면 첫 시트)를 읽어 목록 전체를 바꾼다.
  - 필요한 열: 원본순번, 구분, 파트, 주작업항목, NO, 작업내역, 작업, 수량/시간, 부품액, 공임, 그림코드
  - 작업내역이 비어 있는 행은 올라가지 않는다.
- **엑셀 다운로드**: 항상 서버 최신 내용으로 만든다.

### 1-8. 그림 올리기
- 그림 파일 이름은 **그림코드**와 같아야 한다 (예: USER50002.jpg).
- 파일 한 개는 8MB 이하여야 한다. 넘으면 서버가 거부한다.

## 2. 작업지시서 화면 (휴대폰·PC)

### 2-1. 그림 표시
- 작업지시서의 그림 주소에 앱 버전이 붙었다 (`api/img/<코드>?v=<버전>`).
- 그래서 그림을 바꾼 뒤 휴대폰·PC에서 예전 그림이 캐시에 남아 있는 문제가 줄었다 (0.1.424 이후).
- 확인 필요: 실제 휴대폰에서 새 그림이 바로 보이는지 확인해야 한다.

### 2-2. 작업내역 보기
- 항목의 **보기** 버튼을 누르면 작업내역 목록 팝업이 열린다.
- 확인 필요: 사용자가 "작업지시서 보기 버튼이 응답하지 않는다"고 보고했다. 아직 원인을 찾지 못했다 (로그인 없이는 재현하지 못함).

### 2-3. 목록에서 열기
- 작업지시서 목록의 **보기** 링크는 차량명·차량번호로 작업지시서를 바로 연다.
- 마스터는 공업사 정보(shop)가 함께 넘어간다.
- 목록 보기 링크를 누를 때 저장하지 않은 내용이 있으면 먼저 묻는다.

## 3. 데이터 관리 (오늘 한 작업의 절차)

### 3-1. 엑셀 매핑 업로드 절차
1. 설정 → 주작업항목 그림이미지 매칭에서 엑셀을 업로드한다.
2. 행 수와 그림코드 수를 확인한다 (예: 92행 / 90코드).

### 3-2. 중복 행 문제
- 같은 구분·주작업항목·작업내역·그림코드인데 파트 표기만 다른 행이 있으면 작업지시서에 같은 항목이 두 번 보인다.
- 오늘 원인: 원본순번 99, 101, 116 행이 번호 없는 "프런트"로 적혀 있어 중복이었다. 엑셀에서 삭제했다.
- 매뉴얼에는 "업로드 전 중복 행을 확인한다"를 넣는 것이 좋다.

### 3-3. 그림 업로드 절차
- 그림 폴더의 파일을 그림코드별로 올린다.
- 오늘 올린 폴더: `공임_이미지_캡처(최종본)_취합` (90장, 모두 0.5MB 이하).
- 업로드 후 매칭 상태는 **이미지 존재 여부**로 확인한다.

### 3-4. 매칭 확인 기준
- 매핑 목록의 그림코드마다 그림이 있어야 "매칭"으로 본다.
- 그림이 없는 코드, 매핑이 없는 그림은 목록에서 구분해 확인한다.
